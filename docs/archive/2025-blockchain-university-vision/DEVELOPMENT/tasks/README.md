## 🔄 **Fluxo de Trabalho**

### **Ciclo de Vida da Tarefa**
```
📝 Criada → 🔄 Em andamento → 🧪 Em teste → ✅ Concluída
    ↓              ↓              ↓
  ⏳ Planejado   🚨 Bloqueada   ❌ Rejeitada
```

### **Estados da Tarefa**
- **📝 Criada**: Tarefa criada, aguardando atribuição
- **⏳ Planejada**: Tarefa planejada para sprint
- **🔄 Em andamento**: Tarefa sendo desenvolvida
- **🧪 Em teste**: Tarefa em fase de teste
- **✅ Concluída**: Tarefa finalizada com sucesso
- **🚨 Bloqueada**: Tarefa com impedimentos
- **❌ Rejeitada**: Tarefa rejeitada ou cancelada

### **Transições Permitidas**
- Criada → Planejada
- Planejada → Em andamento
- Em andamento → Em teste
- Em andamento → Bloqueada
- Em teste → Concluída
- Em teste → Rejeitada
- Bloqueada → Em andamento

## 🤖 **Comandos para AI**

### **Comandos de Tarefas**
```bash
# Criar tarefa
@ai create-task [domain] [title] [description] [priority]

# Atualizar tarefa
@ai update-task [ID] [field] [value]

# Listar tarefas
@ai list-tasks [filter] [domain] [status]

# Completar tarefa
@ai complete-task [ID] [notes]

# Bloquear tarefa
@ai block-task [ID] [reason]
```

### **Comandos de Sprint**
```bash
# Criar sprint
@ai create-sprint [name] [start-date] [end-date]

# Planejar sprint
@ai plan-sprint [sprint-id] [task-ids]

# Atualizar sprint
@ai update-sprint [sprint-id] [field] [value]

# Finalizar sprint
@ai complete-sprint [sprint-id] [notes]
```

```bash
# Gerar relatório
@ai generate-report [type] [period]
```

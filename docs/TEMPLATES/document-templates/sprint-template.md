## 📋 **Como Usar Este Template**

1. **Copie** este template
2. **Substitua** os placeholders `[PLACEHOLDER]`
3. **Preencha** todas as seções obrigatórias
4. **Salve** como `sprint-X-name.md`
5. **Adicione** ao sistema de sprints

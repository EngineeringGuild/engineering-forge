## 🎨 **Design System**

### **Componentes Base**

#### **Botões**
- **Primário**: Azul, preenchido
- **Secundário**: Cinza, outline
- **Danger**: Vermelho, para ações destrutivas
- **Ghost**: Transparente, para ações sutis

#### **Cards**
- **Projeto**: Informações e progresso
- **Curso**: Detalhes e estatísticas
- **Componente**: Preview e propriedades
- **Usuário**: Perfil e atividades

#### **Formulários**
- **Input**: Campos de texto
- **Select**: Seleção de opções
- **Checkbox**: Seleção múltipla
- **Radio**: Seleção única

#### **Navegação**
- **Header**: Logo e menu principal
- **Sidebar**: Navegação lateral
- **Breadcrumb**: Caminho atual
- **Pagination**: Navegação de páginas

### **Layouts**

#### **Grid System**
- **12 Colunas**: Sistema flexível
- **Breakpoints**: Mobile, tablet, desktop
- **Gutters**: Espaçamento consistente
- **Alignment**: Alinhamento e justificação

#### **Spacing**
- **Base**: 8px (0.5rem)
- **Multiplos**: 16px, 24px, 32px, 48px
- **Padding**: Espaçamento interno
- **Margin**: Espaçamento externo
